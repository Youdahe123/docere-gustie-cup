The Problem

Students get lost.
Teachers are overwhelmed.

In most K–12 classrooms, a single teacher manages 30+ students with wildly different needs — and there's no scalable way to give each student the personalized guidance they deserve.

30:1

Average student-to-teacher ratio in US public schools.

58%

Of teachers say they don't have time to address individual learning gaps.

2×

Learning gains shown with one-on-one tutoring vs. traditional classroom instruction.

The Solution

Docere is the AI tutor
for every student.

We plug into a school's existing LMS (Moodle, Canvas) and give every student a personal AI tutor that knows their coursework, tracks their progress, and helps them when they're stuck — at any hour.

The AI agent is built on LangGraph with Claude as the backbone. It maintains session state, detects misconceptions, and generates structured notes after each session.

Frontend

What frontend interns own

You'll work in React + TypeScript inside the /frontend directory. Vite handles the dev server. We use Tailwind for styling and Tiptap for rich text.

  • → Student tutoring chat interface & session UX
  • → Instructor dashboard — sessions, gradebook, student overview
  • → Notes viewer & editing (Tiptap integration)
  • → LLM response streaming UI
  • → Responsive design across tablet & desktop
  • → API integration with FastAPI backend

Stack

React 18TypeScriptViteTailwindTiptap

How we ship

Branch off main, open a PR, get a review. We keep PRs small and focused. No force-pushes to main.

Backend

What backend interns own

You'll work in Python + FastAPI inside the /backend directory. We are live in a school right now — and expanding to a second school this summer. A big part of your role is maintaining production infrastructure so real students stay online.

  • → FastAPI routes — tutoring, gradebook, sessions, auth
  • → LangGraph agent improvements & prompt tuning
  • → Moodle / Canvas LMS integration & sync
  • → Google Sheets gradebook export
  • → Database schema (SQLAlchemy + SQLite → Postgres)
  • → Infra stability — uptime, monitoring, second school rollout

Stack

PythonFastAPILangGraphClaude APISQLAlchemy

Key pattern

LLM responses wrap structured data in ```artifact blocks. Backend parses these with regex. Learn this early.
